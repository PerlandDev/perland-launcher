# Frequently asked questions

## How do I choose which graphics card the launcher uses?

Open **Settings** in the launcher and look for the **Graphics card** selector, below the default memory setting. Choose between:

- **Automatic**: the system decides (as before).
- **Dedicated**: uses the higher-performance card.
- **Integrated**: uses the power-saving card.

Below the selector there is a line listing the graphics cards detected on your computer, so you know which ones you are choosing between.

Notes:

- If your computer only has one graphics card, the selector appears disabled and says so.
- On macOS this option is not available: the system decides, and the selector appears disabled.
- The change takes effect the next time the game starts; it does not affect a game already running.
- It applies to all of your instances alike; there is no per-instance option yet.

If you don't see this selector, your launcher version may not include this feature yet.
