# Preset themes and text font (#40) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let players pick a preset colour theme and a text font in Settings without breaking the colour roles (#40, the follow-up to #37 item 2).

**Architecture:** One PR off `main` on branch `claude/gifted-shannon-e7veg2`.
- **Core:** two new settings, `theme` and `font`, with serde defaults so old files load unchanged.
- **UI:** each theme is a `:root[data-theme=…]` block in `ui/src/styles/app.css` that overrides only the neutral tokens. The font choice is a `:root[data-font=…]` block that overrides `--font-sans`. The settings are applied to `<html>` and mirrored to `localStorage`, so the next start paints the chosen theme before the settings load.

**Tech Stack:** Rust (serde), React 19, Tailwind v4 `@theme` tokens, Vitest.

**Spec:** this document. The owner decided on 2026-10-16: "a few preset themes", and handed every other call to the implementer. Calls marked **(our call)** are for owner review on the PR.

## Decisions

- **Roles never change (our call, from PRODUCT.md and DESIGN.md):**
  - **Fixed in every theme:** `amber`, `amber-hi`, `lime`, `coral`, `blue` and `blue-ink`.
  - **What a theme overrides:** only the neutrals `ground`, `panel`, `raised`, `line`, `ink` and `ink-dim`, plus the step colours `dirt` and `dirt-deep`. `line` is the "thin accent line" the reporter asked about.
  - **Dark only:** every theme stays dark ("dark only for v1" stands).
- **Four themes (our call).** All tones are pixel-world materials, and each has a name in both languages:

  | key | en | es | feel | ground | panel | raised | line | ink | ink-dim | dirt | dirt-deep |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | `laminate` (default) | Laminate | Laminado | today's warm brown-black | `#181410` | `#221c17` | `#2e261f` | `#463a2f` | `#f6f1e7` | `#c5b9a8` | `#7a4a2a` | `#4e2e19` |
  | `stone` | Stone | Piedra | cool deepslate grey | `#141619` | `#1d2024` | `#282c31` | `#3f454d` | `#eef1f4` | `#b6bec8` | `#5b636d` | `#363b42` |
  | `night` | Night | Noche | deep blue night sky | `#10131f` | `#181c2c` | `#22283b` | `#363f5c` | `#eef0fa` | `#b3bad3` | `#4a4f8a` | `#2b2f57` |
  | `forest` | Forest | Bosque | dark moss green | `#111712` | `#19211a` | `#232d24` | `#3a4a3b` | `#eef3ea` | `#b5c3b0` | `#4f6b3a` | `#2f4223` |

  The implementer may tune hex values for contrast or harmony through `/impeccable`. Every value must pass the contrast test below.
- **Contrast (hard rule).**
  - Against each theme's `ground`, `panel` and `raised`, these text colours reach at least 4.5:1 (WCAG AA): `ink`, `ink-dim`, `blue-ink` and `coral`.
  - `ground` text on `amber` and on `coral` (lit button faces) reaches at least 4.5:1.
  - `lime` against `ground` reaches at least 3:1 (non-text UI).
  - A Vitest test parses `app.css`, so a theme can never ship below these.
- **Generated art (our call):**
  - The marquee landscapes, avatars and plot icons keep their own palettes. They are pictures, not chrome.
  - Exception: `ui/src/art/random.ts` exports `GROUND`/`DIRT` for the plot icon's base. Leave them as is, since a plot icon is a little landscape tile.
- **Font (our call):** a "Text font" choice. It changes body text only; the Bungee display face stays as the brand.
  - `hyperlegible` (default): Atkinson Hyperlegible Next, today's font.
  - `system`: the operating system's own UI font, `system-ui, 'Segoe UI', sans-serif`. It needs no download.

  Two options keep this honest and lightweight. Adding more bundled fonts is deferred.
- **Settings model:**
  - `Settings.theme: Theme { Laminate (default, serde other), Stone, Night, Forest }` (lowercase).
  - `Settings.font: UiFont { Hyperlegible (default, serde other), System }` (lowercase).
  - Both are camelCase keys. An unknown value loads as the default.
- **Settings screen (our call):** a new "Appearance" group.
  - **Theme:** a radiogroup of four swatch keys. Each key is a small sample of that theme: a ground tile, a raised key on its step, the line, and an amber dot, plus the theme's name.
  - **Text font:** a two-option segmented control, with each option label set in its own font.
  - The existing "Instance icons" control moves into the same group.
  - Choosing applies at once, so the whole app changes live, and saves like the other settings.
- **Applying:** a small `applyAppearance({ theme, font })` sets `document.documentElement.dataset.theme` and `.dataset.font`.
  - It runs whenever the settings change, and also before the first render from a `localStorage` mirror wrapped in try/catch, so the start doesn't flash the old theme.
  - First run with no settings yet → defaults.
- **Copy:**
  - `settings.appearance`: "Appearance" / "Apariencia".
  - `settings.theme`: "Theme" / "Tema".
  - `settings.themes.laminate|stone|night|forest`: the names in the table.
  - `settings.font`: "Text font" / "Fuente del texto".
  - `settings.fontHyperlegible`: "Easy to read" / "Fácil de leer".
  - `settings.fontSystem`: "This computer's" / "La de tu computadora".
